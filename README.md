# ALCWARE OpenDesign package v3

This is a hand-authored OpenDesign package intended to preserve the existing ALCWARE cross-product design system instead of re-extracting it into a generic brand seed.

Important: import the **whole `alcware/` folder/repository as a Design System package**. Do not create a new system by pasting only the prose into the fast brand-extraction flow if exact component fidelity is required.

Canonical files:
- `manifest.json` — identity and declared package paths
- `DESIGN.md` — design meaning and rules
- `tokens.css` — exact compiled values
- `components.html` — visual component fixture
- `USAGE.md` — agent read order
- `preview/` — focused human previews
